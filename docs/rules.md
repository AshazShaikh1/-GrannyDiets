# Rules

Never change the database without permission.

Never install unnecessary packages.

Always use TypeScript.

Never use JavaScript.

Always use Server Components unless Client Components are required.

Keep components small.

Maximum component length:

200 lines

Never hardcode values.

Always use environment variables.

Never duplicate code.

Always use reusable components.

Never create inline styles.

Use Tailwind only.

Never commit secrets.

Never remove existing functionality.

Always explain major architectural decisions.

Before creating a new dependency, justify why it is needed.
