# Granny Diets

## Project

Granny Diets is a modern ecommerce platform for selling handcrafted Indian pickles and sauces.

The current website exists, but this project is a complete rebuild using a modern technology stack.

The goal is NOT to redesign the business.

The goal is to recreate the current website while improving:

- Performance
- Maintainability
- Security
- User Experience
- Admin Experience

The client currently has six products but the architecture should support hundreds.

---

## Business

Products

- Mango Pickle
- Lemon Pickle
- Green Chilli Pickle
- Amla Pickle
- Garlic Pickle
- Garlic Sauce

---

Business Rules

- Free Shipping
- COD Available
- 5% Extra Discount on Prepaid Orders
- Shelf Life: 9 Months

---

Special Requirement

Developer receives 50% commission from every order.

The application automatically tracks:

- Sales
- Commission
- Weekly settlements
- Outstanding balance

The website can be suspended if invoices remain unpaid.
