# Database

Tables

- profiles
- addresses
- categories
- products
- product_images
- cart_items
- orders
- order_items
- payments
- reviews
- settings
- commission_periods
- order_commissions

All IDs use UUID.

Products belong to categories.

Orders contain multiple order items.

Users have multiple addresses.

Products have multiple images.

Commission is tracked weekly.

Do not change the schema without approval.
